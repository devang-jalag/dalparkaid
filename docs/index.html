PRODUCTION CODEBASE ARCHITECTURE

How We Predict Lot Occupancy Without Asphalt Sensors

Municipalities and universities avoid smart parking because trenching inductive loops costs over $550 per stall. Our React Native and Firebase engine achieves stall-tier accuracy through three mathematical layers:

LAYER 01 src/utils/engine.js

Deterministic Campus Load Baseline

Calculates base pressure across all 28 Dalhousie lots using time-of-day curves, lot classification (Commuter, Residence, Parkade, Event), scraped Dal.ca academic calendar overrides, and real-time Open-Meteo weather codes.

score = clamp(base + hourDelta + weatherDelta + lotSizeDelta + academicDay + campusLoad)
LAYER 02 30m Geofence Verification

Exponential Decay Crowd Telemetry

Drivers within 30 meters of a lot submit 1-to-5 occupancy reports. Each report is weighted by exponential freshness decay (45-minute half-life), camera photo proof (1.15x boost), user trust score, and community upvotes.

weight = exp(-ageMins / 45) * proof(1.15) * trust(0.7..1.3) * voteWeight
LAYER 03 42-Day Rolling Memory

Short-Guard Alpha Blending

Blends deterministic predictions with live crowd telemetry and 42-day historical weekday/hour patterns. When a verified report arrives within 15 minutes, a short-guard floor locks prediction drift within tight confidence bounds.

final = round((1 - alpha) * engineScore + alpha * crowdScore)
